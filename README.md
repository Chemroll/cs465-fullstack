Getting Started
To install and run this application on your own machine, you'll need to install the frameworks listed above, as well as be running an IDE such as Visual Studio Code.

Prerequisites
Start by ensuring you have npm installed on your machine.

Installation process
To install and run the application, follow the instructions below.
Clone the repo
Open the folder in VS Code
Navigate to the "app_admin" folder
Install NPM packages
Navigate to the "app_server" folder
Install NPM packages
In the "app_server" folder, start the server
In the "app_admin" folder, start the Angular server
Open a web browser and navigate to "http://localhost:3000" to access the API
Open another browser tab / window and navigate to "http://localhost:4200" to access the backend

Usage
The main customer page uses standard HTML with javascript and handlebars to access the backend database (served by MongoDB local hosting) and display available information to customers.

Backend SPA (using Angular, Express, node.js, and MongoDB)
A single-page application was delivered to administrators by the project's administrative backend, which used the Angular, Express, node.js, and MongoDB (MEAN) stack system.  A user might access this SPA, log in, and then add, edit, and delete trips.  Customers could see the results of any changes made in the backend reflected immediately on the front end website.
